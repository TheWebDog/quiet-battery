# Quiet Battery · 外设电量

<img src="assets/source/software/icon-256.png" width="80" alt="Quiet Battery">

Windows 原生外设电量托盘工具。Rust + Win32，单 EXE，后台低频读取；按设备保存电量、托盘选择和低电提醒。

**[下载 Windows x64 稳定版](https://github.com/TheWebDog/quiet-battery/releases/latest)** · [设备扩展](docs/ADDING_DEVICES.md) · [商业授权](COMMERCIAL.md)

## 使用

1. 在 Releases 下载 `quiet-battery-windows-x64.exe`，放到准备长期保留的文件夹后运行，直接显示主界面；已有实例时再次双击会恢复同一个窗口。无需安装 Rust、Python 或网页运行时。
2. 左键托盘打开主窗口，右键打开菜单。受支持的鼠标默认监控；其他设备通过“添加设备”选择。
3. 在“设置”开启自启、设置低电阈值，以及分别选择设备的托盘和提醒。登录自启只在托盘运行，不弹主窗口。关闭窗口继续运行；菜单“退出”才结束程序。

设置和上次成功电量统一保存在 `%LOCALAPPDATA%\QuietBattery\devices-v2.state`，EXE旁不再创建文件或文件夹。首次升级自动迁移原EXE旁 `data` 中的设置；确认新文件内容一致后删除旧设置及过期运行快照，只删除空的旧 `data` 文件夹，不动其他文件。新位置已有设置时优先使用；冲突的旧设置保留，避免覆盖丢失。若升级前移动过EXE，请把旧 `data` 一起放回新EXE旁，运行一次完成迁移。

移动EXE不再影响设置；开启自启后移动EXE仍需重新设置自启。卸载时先关闭自启、退出，再删除EXE；需要清除偏好时删除上述用户数据目录。`--status` 只在请求时通过内存消息返回JSON，不自动保存诊断文件。

启动失败会弹出具体错误和处理建议，不另写错误日志；命令行诊断仍输出JSON，便于脚本处理。设置被占用、拒绝读取或文件头无法识别时停止启动，保留原文件，不用默认设置覆盖。

程序未做代码签名。Windows 如提示未知发布者，可先对照 Release 中的 SHA256 校验下载文件。

从v0.3.0起保留既有Release和附件，不再自动清理旧版本；源码和Git标签继续保留。

## 功能

- 型号、真实百分比、十格满量程电池和手动刷新。精细数据支持部分填充；纯档位由适配器归一化，例如3/4→75%。
- 休眠或超时保留上次电量；确认断开才隐藏，重连自动恢复。没有成功值时显示未知。
- 每台设备独立托盘：设备填色图标与连续电量尺，悬停查看百分比。主窗口与托盘共用设备造型。
- 默认低电阈值20%：严格低于时提醒一次，严格超过后恢复资格；充电时抑制，确认充电结束且仍低电时再提醒。重启、重连、关闭再开启提醒不重置已通知周期。使用 Windows 原生通知。
- 设备提供可确认的充电状态时显示闪电，不猜测充电和续航。

## 提供设备适配信息

打开“添加设备”，找到对应设备，点击**复制信息**后直接粘贴给开发者或agent；也可点击**导出文件**，选择位置保存JSON。已监控的设备同样有这两个入口。采集在后台运行，完成后按钮显示“已复制”或“已导出”。

报告只包含所选物理设备：重新采集的HID接口及报告长度、适配器匹配/未匹配原因、软件/系统版本、上次监控读数与时间。能可靠关联到已配对BLE端点时，另查标准电池服务、读/订阅属性、现有订阅和读取错误。默认隐藏原始路径、容器ID和蓝牙地址，不查询序列号，不自动配对，不发送未知厂商命令。

发送信息时附上准确品牌型号、连接方式、接收器版本（如1K/4K/8K）；有官方驱动链接也可附上。报告用于定位协议和接口，适配进度仍需区分资料、模拟测试与真机结果，详见[扩展指南](docs/ADDING_DEVICES.md)。保存窗口使用同一EXE的临时子进程，选完即退出，避免系统文件窗口缓存增加常驻占用；取消不导出文件，不新增日志目录。

### 测试多彩 M900 Pro

使用2.4G接收器，打开“添加设备”点“手动刷新”，同时连续移动鼠标约3秒。收到匹配状态帧后自动识别并默认监控；休眠或静止时可能没有新帧，已有电量会保留。充电/满电标志和百分比按设备原值显示。

若仍未识别，在添加页对对应设备点“复制信息”或“导出文件”，同时提供底部准确型号、接收器版本及连接方式。M900 Pro同名不同主控、Ultra/Pro+或替换接收器不自动包含，详见设备支持表。

## 构建与继续开发

需要 Windows、Rust stable（维护者本轮使用1.94.0；贡献者报告使用1.99.1）、MSVC 工具链及 Windows SDK：

```powershell
./tools/build.ps1
```

脚本执行格式检查、单元测试、Clippy 和 release 构建，成品为 `dist/quiet-battery.exe`。依赖及构建缓存保存在 `.build` 下。提交的图标资产可直接构建；只有修改图标时才需要 Python / Pillow。
